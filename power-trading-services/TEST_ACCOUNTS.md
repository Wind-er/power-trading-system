## 使用说明

1. 所有测试账号的密码都是：**123456**
2. 系统首次启动时会自动创建这些账号
3. 如果账号已存在，则不会重复创建
4. 建议使用不同的账号测试不同的功能：
   - 使用购电商账号发布买入订单
   - 使用发电商账号发布卖出订单
   - 测试订单撮合功能

## 测试场景建议

### 场景1：基本交易流程
1. 使用 `generator1` 登录，发布一个卖出订单（例如：峰时电力，100 MWh，价格 500 元/MWh）
2. 使用 `buyer1` 登录，发布一个买入订单（例如：峰时电力，100 MWh，价格 550 元/MWh）
3. 系统会自动撮合这两个订单，生成交易记录

### 场景2：部分成交
1. 使用 `generator1` 发布卖出订单：100 MWh
2. 使用 `buyer1` 发布买入订单：50 MWh（价格匹配）
3. 订单会部分成交，剩余50 MWh继续等待撮合

### 场景3：价格优先测试
1. 使用 `generator1` 发布卖出订单：100 MWh，价格 500 元/MWh
2. 使用 `generator2` 发布卖出订单：100 MWh，价格 480 元/MWh
3. 使用 `buyer1` 发布买入订单：100 MWh，价格 550 元/MWh
4. 系统会优先匹配价格更低的卖出订单（generator2的订单）
