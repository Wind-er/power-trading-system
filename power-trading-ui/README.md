# 电力交易系统前端

## 技术栈
- React 18
- TypeScript
- React Router
- Axios
- Vite

## 快速开始

### 安装依赖
```bash
npm install
```

### 开发模式
```bash
npm run dev
```

应用将在 http://localhost:3000 启动

### 构建生产版本
```bash
npm run build
```

## 功能模块

- 用户认证（登录/注册）
- 商品管理
- 订单管理（发布、查看、撤销）
- 交易记录查询
- 市场行情展示
- 个人中心

## 页面说明

- `/login` - 登录页面
- `/register` - 注册页面
- `/` - 首页（市场行情）
- `/products` - 商品列表
- `/orders` - 订单管理
- `/orders/create` - 发布订单
- `/trades` - 交易记录
- `/profile` - 个人中心
